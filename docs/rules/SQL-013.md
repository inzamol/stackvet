# SQL-013: Session flush or commit called inside loop

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-013` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Calling session.flush() or session.commit() inside loops creates high database roundtrip overhead. Use bulk insert or single commit after loop.

## Why This Matters
Detecting and addressing session flush or commit called inside loop prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Move session.commit() outside the loop or use session.execute(insert(Model), batch_data).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-013
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-013" = "off" # or "warning", "error"
```
