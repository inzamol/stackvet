# SQL-001: Potential N+1 database query in loop

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-001` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Executing database queries (session.execute, session.query, session.get, or select()) inside for/while loops causes N+1 performance degradation.

## Why This Matters
Detecting and addressing potential n+1 database query in loop prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Batch query objects using 'select(...).where(Model.id.in_(ids))' or eager relationship options (e.g. joinedload/selectinload).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-001" = "off" # or "warning", "error"
```
