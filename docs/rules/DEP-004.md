# DEP-004: Python compatibility mismatch

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DEP-004` |
| **Category** | `dependency` |
| **Default Severity** | `WARNING` |

## Description
A package requires a Python version incompatible with the target project runtime.

## Why This Matters
Detecting and addressing python compatibility mismatch prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Update your target Python version or install a version of the package compatible with your Python runtime.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DEP-004
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DEP-004" = "off" # or "warning", "error"
```
