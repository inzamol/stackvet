# PKG-001: Missing package metadata

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `PKG-001` |
| **Category** | `packaging` |
| **Default Severity** | `WARNING` |

## Description
Essential packaging metadata (such as project name, version, or description) is missing.

## Why This Matters
Detecting and addressing missing package metadata prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Provide project name and version in pyproject.toml [project] table.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore PKG-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"PKG-001" = "off" # or "warning", "error"
```
