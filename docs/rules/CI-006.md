# CI-006: Missing concurrency cancellation in PR workflow

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `CI-006` |
| **Category** | `ci` |
| **Default Severity** | `INFO` |

## Description
Pull request workflow lacks concurrency cancellation, causing redundant runner minutes.

## Why This Matters
Detecting and addressing missing concurrency cancellation in pr workflow prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add concurrency group with 'cancel-in-progress: true'.


