# ARC-002: Architectural circular component dependency

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `ARC-002` |
| **Category** | `architecture` |
| **Default Severity** | `ERROR` |

## Description
A circular dependency cycle exists between high-level architectural components or layers.

## Why This Matters
Detecting and addressing architectural circular component dependency prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Decouple the architectural components by extracting shared utilities or introducing abstraction layers.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore ARC-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"ARC-002" = "off" # or "warning", "error"
```
