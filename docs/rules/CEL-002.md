# CEL-002: Missing task timeout limits in Celery task

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `CEL-002` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Celery task has no 'time_limit' or 'soft_time_limit' configured.

## Why This Matters
Detecting and addressing missing task timeout limits in celery task prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Specify 'time_limit' and 'soft_time_limit' on task decorator: @shared_task(time_limit=300, soft_time_limit=240).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore CEL-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"CEL-002" = "off" # or "warning", "error"
```
