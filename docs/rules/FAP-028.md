# FAP-028: Raw json.loads called on request body

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-028` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Calling 'json.loads(await request.body())' or 'json.loads(request.body)' is an anti-pattern; FastAPI and Starlette provide an optimized built-in 'await request.json()' method.

## Why This Matters
Detecting and addressing raw json.loads called on request body prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Replace 'json.loads(await request.body())' with 'await request.json()'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-028
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-028" = "off" # or "warning", "error"
```
