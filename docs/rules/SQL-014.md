# SQL-014: Deprecated declarative_base() function

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-014` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Using legacy declarative_base() instead of modern SQLAlchemy 2.0 class Base(DeclarativeBase): pass.

## Why This Matters
Detecting and addressing deprecated declarative_base() function prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Define 'class Base(DeclarativeBase): pass' from sqlalchemy.orm.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-014
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-014" = "off" # or "warning", "error"
```
