# SQL-008: create_engine missing pool_pre_ping connection health check

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-008` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Creating a database engine without 'pool_pre_ping=True' can lead to runtime disconnect errors when idle connections are closed by firewalls/servers.

## Why This Matters
Detecting and addressing create_engine missing pool_pre_ping connection health check prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add 'pool_pre_ping=True' to create_engine() / create_async_engine().


