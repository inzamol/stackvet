# SEC-003: Vulnerability advisory database refresh failed

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SEC-003` |
| **Category** | `security` |
| **Default Severity** | `WARNING` |

## Description
A refresh of the vulnerability advisory database was requested or attempted, but failed due to a network or service error. StackVet will continue using cached advisory data.

## Why This Matters
When an explicit database refresh fails, vulnerability scanning may rely on cached advisories that do not include the latest security advisories or newly disclosed CVEs. Failing silently or reporting a completely clean scan when a refresh was requested can create a false sense of security.

## Remediation
Check your internet connection, verify proxy settings, or run without `--refresh-vuln-cache` to use cached advisories without attempting network synchronization.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SEC-003
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SEC-003" = "off" # or "warning", "error"
```
