# FAP-003: Missing response model or return type annotation

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-003` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
FastAPI route endpoint does not declare a response_model argument or return type annotation, disabling schema validation and response serialization.

## Why This Matters
Detecting and addressing missing response model or return type annotation prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add a return type annotation (-> ResponseModel) or pass response_model to the route decorator.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-003
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-003" = "off" # or "warning", "error"
```
