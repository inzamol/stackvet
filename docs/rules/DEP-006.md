# DEP-006: Vulnerable transitive dependency

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DEP-006` |
| **Category** | `dependency` |
| **Default Severity** | `ERROR` |

## Description
A security vulnerability has been identified in a direct or transitive dependency.

## Why This Matters
Detecting and addressing vulnerable transitive dependency prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Update the vulnerable dependency or apply vendor security patches.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DEP-006
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DEP-006" = "off" # or "warning", "error"
```
