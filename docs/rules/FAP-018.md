# FAP-018: Global in-memory state mutation in route handler

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-018` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Route handler mutates global/module-level collections or variables without synchronization locks, causing concurrency bugs.

## Why This Matters
Detecting and addressing global in-memory state mutation in route handler prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use a proper database, Redis cache, or an asyncio.Lock for shared state.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-018
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-018" = "off" # or "warning", "error"
```
