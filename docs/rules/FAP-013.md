# FAP-013: Untracked asyncio.create_task in route handler

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-013` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Spawning raw asyncio.create_task inside route handlers without background task management can cause lost exceptions and unhandled crashes.

## Why This Matters
Detecting and addressing untracked asyncio.create_task in route handler prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use FastAPI's built-in BackgroundTasks ('background_tasks.add_task(...)') for request-scoped background jobs.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-013
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-013" = "off" # or "warning", "error"
```
