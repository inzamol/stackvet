# DEP-003: No direct import detected

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DEP-003` |
| **Category** | `dependency` |
| **Default Severity** | `WARNING` |

## Description
A package is declared as a direct dependency, but no direct imports were detected across project source files. This detects the absence of a detected direct import, not proof that the dependency is unused. Dependencies may still be required at runtime through plugins, configuration, framework integration, CLI entrypoints, or indirect mechanisms.

## Why This Matters
Detecting and addressing no direct import detected prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Verify if this dependency is used dynamically, required as a plugin/driver/runtime configuration, or can be safely removed.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DEP-003
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DEP-003" = "off" # or "warning", "error"
```
