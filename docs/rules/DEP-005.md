# DEP-005: Installed/declaration mismatch

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DEP-005` |
| **Category** | `dependency` |
| **Default Severity** | `WARNING` |

## Description
The package version installed in the virtualenv does not match the pinned requirement in project declaration.

## Why This Matters
Detecting and addressing installed/declaration mismatch prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Sync your virtual environment using your package manager (e.g. `uv sync` or `poetry install`).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DEP-005
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DEP-005" = "off" # or "warning", "error"
```
