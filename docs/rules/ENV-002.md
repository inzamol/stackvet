# ENV-002: Docker runtime drift

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `ENV-002` |
| **Category** | `environment` |
| **Default Severity** | `WARNING` |

## Description
The Python version in Dockerfile/docker-compose differs from the project's target runtime.

## Why This Matters
Detecting and addressing docker runtime drift prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Update the base image tag in your Dockerfile to match your project's target Python version.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore ENV-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"ENV-002" = "off" # or "warning", "error"
```
