# FAP-025: Returned HTTPException instance instead of raise

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-025` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Returning an HTTPException instance in a route handler returns a 200 OK HTTP response with the serialized exception object instead of raising an error.

## Why This Matters
Detecting and addressing returned httpexception instance instead of raise prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use 'raise HTTPException(...)' instead of 'return HTTPException(...)'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-025
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-025" = "off" # or "warning", "error"
```
