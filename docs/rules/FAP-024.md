# FAP-024: Redundant duplicate dependency declaration

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-024` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Route handler declares multiple parameters resolving the exact same dependency callable.

## Why This Matters
Detecting and addressing redundant duplicate dependency declaration prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Consolidate duplicate dependencies into a single parameter.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-024
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-024" = "off" # or "warning", "error"
```
