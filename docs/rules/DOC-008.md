# DOC-008: Missing PYTHONUNBUFFERED=1 environment variable

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-008` |
| **Category** | `docker` |
| **Default Severity** | `INFO` |

## Description
Python buffers stdout/stderr by default, which delays or prevents real-time container log streaming.

## Why This Matters
Detecting and addressing missing pythonunbuffered=1 environment variable prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add 'ENV PYTHONUNBUFFERED=1' to your Dockerfile to ensure unbuffered real-time log output.
