# SQL-025: Deprecated engine.execute() or engine.scalar() direct call

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-025` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Calling engine.execute() or engine.scalar() directly is removed in SQLAlchemy 2.0.

## Why This Matters
Detecting and addressing deprecated engine.execute() or engine.scalar() direct call prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use explicit connection contexts: 'with engine.connect() as conn: result = conn.execute(stmt)'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-025
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-025" = "off" # or "warning", "error"
```
