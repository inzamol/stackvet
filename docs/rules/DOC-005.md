# DOC-005: Missing --no-cache-dir in pip install

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-005` |
| **Category** | `docker` |
| **Default Severity** | `INFO` |

## Description
pip install inside Dockerfile runs without '--no-cache-dir', which unnecessarily bloats the container layer with cached wheels.

## Why This Matters
Detecting and addressing missing --no-cache-dir in pip install prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add '--no-cache-dir' to pip install commands (e.g. 'pip install --no-cache-dir -r requirements.txt').
