# SQL-026: AsyncSession instantiated without async context manager or await close()

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-026` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
AsyncSession created without 'async with' context manager or explicit 'await session.close()', causing connection leaks in async tasks.

## Why This Matters
Detecting and addressing asyncsession instantiated without async context manager or await close() prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use 'async with AsyncSessionLocal() as session:' or ensure 'await session.close()' in a finally block.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-026
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-026" = "off" # or "warning", "error"
```
