# DJG-002: Hardcoded SECRET_KEY in Django settings

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DJG-002` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Hardcoded SECRET_KEY literal detected in settings. Secrets must be loaded from environment variables.

## Why This Matters
Detecting and addressing hardcoded secret_key in django settings prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Load SECRET_KEY from environment: os.environ['DJANGO_SECRET_KEY'].

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DJG-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DJG-002" = "off" # or "warning", "error"
```
