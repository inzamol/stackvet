# CEL-003: Unbounded retry policy on Celery task

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `CEL-003` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Celery task permits unlimited retries, risking broker congestion.

## Why This Matters
Detecting and addressing unbounded retry policy on celery task prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Set explicit 'max_retries' (e.g. max_retries=3, default_retry_delay=60).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore CEL-003
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"CEL-003" = "off" # or "warning", "error"
```
