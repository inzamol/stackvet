# SQL-010: Hardcoded database credentials in connection URL

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-010` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Database URL contains plain-text passwords or secret credentials in source code instead of loading from environment variables.

## Why This Matters
Detecting and addressing hardcoded database credentials in connection url prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Read database connection strings from environment variables (e.g. os.getenv('DATABASE_URL')).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-010
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-010" = "off" # or "warning", "error"
```
