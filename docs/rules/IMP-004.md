# IMP-004: Deprecated or removed standard library module

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `IMP-004` |
| **Category** | `compatibility` |
| **Default Severity** | `ERROR` |

## Description
A standard library module imported in source code was deprecated or completely removed in modern Python (PEP 594).

## Why This Matters
Detecting and addressing deprecated or removed standard library module prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Replace the removed stdlib module with its modern replacement (e.g. importlib instead of imp, subprocess instead of pipes).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore IMP-004
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"IMP-004" = "off" # or "warning", "error"
```
