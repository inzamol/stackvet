# FAP-004: Insecure CORS or debug configuration

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-004` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
CORSMiddleware configured with allow_origins=['*'] and allow_credentials=True, or FastAPI instantiated with debug=True.

## Why This Matters
Detecting and addressing insecure cors or debug configuration prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Specify explicit trusted origins in allow_origins when credentials are enabled, and disable debug mode in production.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-004
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-004" = "off" # or "warning", "error"
```
