# SQL-024: Insecure unencrypted remote database connection URL

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-024` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Remote database connection URL targeting external hosts does not specify sslmode=require or ssl=true.

## Why This Matters
Detecting and addressing insecure unencrypted remote database connection url prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Append '?sslmode=require' (PostgreSQL) or '?ssl=true' to production database connection strings.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-024
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-024" = "off" # or "warning", "error"
```
