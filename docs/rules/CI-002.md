# CI-002: Unfrozen dependency installation in CI

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `CI-002` |
| **Category** | `ci` |
| **Default Severity** | `WARNING` |

## Description
CI workflow installs dependencies without lockfiles or hash verification.

## Why This Matters
Detecting and addressing unfrozen dependency installation in ci prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use lockfiles (e.g. 'uv sync --frozen', 'poetry install --sync', or 'pip-sync') in CI workflows.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore CI-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"CI-002" = "off" # or "warning", "error"
```
