# IMP-003: Unused / orphan local module

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `IMP-003` |
| **Category** | `architecture` |
| **Default Severity** | `WARNING` |

## Description
A Python source file exists in the project but is never imported or referenced by any other module, entry point, or test file.

## Why This Matters
Detecting and addressing unused / orphan local module prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Review if this module is obsolete and can be safely deleted or integrated into your package exports.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore IMP-003
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"IMP-003" = "off" # or "warning", "error"
```
