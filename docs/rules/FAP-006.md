# FAP-006: Route path parameter template mismatch

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-006` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
A path parameter defined in the route URL template (e.g. '/users/{user_id}') does not match any parameter in the handler function signature.

## Why This Matters
Detecting and addressing route path parameter template mismatch prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Ensure all {param} placeholders in route URL decorators match parameter names in the endpoint function signature.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-006
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-006" = "off" # or "warning", "error"
```
