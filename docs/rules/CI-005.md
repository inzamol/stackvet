# CI-005: Insecure secret or token in CI workflow

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `CI-005` |
| **Category** | `ci` |
| **Default Severity** | `ERROR` |

## Description
Potential plaintext secret or token literal detected in workflow file.

## Why This Matters
Detecting and addressing insecure secret or token in ci workflow prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Store credentials in repository secrets (${{ secrets.MY_SECRET }}).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore CI-005
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"CI-005" = "off" # or "warning", "error"
```
