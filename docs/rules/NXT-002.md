# NXT-002: Client Component Private Secret

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `NXT-002` |
| **Category** | `nextjs` |
| **Default Severity** | `CRITICAL` |

## Description
Client component references server-only environment variable.

## Why This Matters
Detecting and addressing client component private secret prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Prefix variable with NEXT_PUBLIC_ if intended for browser, or access on server.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore NXT-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"NXT-002" = "off" # or "warning", "error"
```
