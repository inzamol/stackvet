# DEP-001: Dependency constraint conflict

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DEP-001` |
| **Category** | `dependency` |
| **Default Severity** | `ERROR` |

## Description
Two or more declared or transitive dependencies have incompatible version constraints.

## Why This Matters
Detecting and addressing dependency constraint conflict prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Upgrade the conflicting package or loosen the version pin to satisfy all requirements.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DEP-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DEP-001" = "off" # or "warning", "error"
```
