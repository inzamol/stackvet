# RCT-002: Conditional Hook Call

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `RCT-002` |
| **Category** | `react` |
| **Default Severity** | `ERROR` |

## Description
React hook invoked conditionally inside if-statement or loop.

## Why This Matters
Detecting and addressing conditional hook call prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Move hook calls to the top level of the component function.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore RCT-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"RCT-002" = "off" # or "warning", "error"
```
