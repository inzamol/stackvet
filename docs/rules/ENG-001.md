# ENG-001: Analyzer execution failed

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `ENG-001` |
| **Category** | `engine` |
| **Default Severity** | `ERROR` |

## Description
An analyzer raised an unexpected exception during execution.

## Why This Matters
Detecting and addressing analyzer execution failed prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Check the error message or report a bug to the analyzer maintainer.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore ENG-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"ENG-001" = "off" # or "warning", "error"
```
