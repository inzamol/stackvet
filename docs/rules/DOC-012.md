# DOC-012: ADD instruction used for local file copy

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-012` |
| **Category** | `docker` |
| **Default Severity** | `INFO` |

## Description
The ADD instruction was used to copy local files where COPY is preferred for predictability and security.

## Why This Matters
Detecting and addressing add instruction used for local file copy prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Replace 'ADD' with 'COPY' unless automatic tar archive extraction or remote URL fetching is explicitly intended.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DOC-012
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DOC-012" = "off" # or "warning", "error"
```
