# FAP-008: Deprecated @app.on_event lifecycle hook

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-008` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Using deprecated @app.on_event('startup' / 'shutdown') handlers instead of modern lifespan context managers.

## Why This Matters
Detecting and addressing deprecated @app.on_event lifecycle hook prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Migrate @app.on_event to '@asynccontextmanager async def lifespan(app: FastAPI)' and pass to FastAPI(lifespan=lifespan).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-008
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-008" = "off" # or "warning", "error"
```
