# SQL-015: SQLite engine missing check_same_thread=False in multi-threaded application

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-015` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
SQLite engine initialized without connect_args={'check_same_thread': False} can cause ProgrammingError in multi-threaded web applications.

## Why This Matters
Detecting and addressing sqlite engine missing check_same_thread=false in multi-threaded application prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Pass connect_args={'check_same_thread': False} to create_engine() when using SQLite in web applications.

```python

```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]

```
