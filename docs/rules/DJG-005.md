# DJG-005: Django ForeignKey missing explicit on_delete

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DJG-005` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
models.ForeignKey declared without required 'on_delete' argument.

## Why This Matters
Detecting and addressing django foreignkey missing explicit on_delete prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Specify explicit on_delete behavior: models.CASCADE, models.PROTECT, or models.SET_NULL.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DJG-005
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DJG-005" = "off" # or "warning", "error"
```
