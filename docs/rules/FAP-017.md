# FAP-017: Non-standard HTTP status code on POST or DELETE

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-017` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Mutation routes (POST/DELETE) return default 200 OK instead of standard REST status codes (201 Created or 204 No Content).

## Why This Matters
Detecting and addressing non-standard http status code on post or delete prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Specify status_code=status.HTTP_201_CREATED on POST routes or status.HTTP_204_NO_CONTENT on DELETE routes.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-017
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-017" = "off" # or "warning", "error"
```
