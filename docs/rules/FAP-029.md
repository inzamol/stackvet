# FAP-029: StreamingResponse initialized without media_type

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-029` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Instantiating StreamingResponse without specifying 'media_type' can cause clients to misinterpret the streamed content format.

## Why This Matters
Detecting and addressing streamingresponse initialized without media_type prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Pass an explicit media_type argument (e.g. StreamingResponse(stream, media_type='application/json')).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-029
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-029" = "off" # or "warning", "error"
```
