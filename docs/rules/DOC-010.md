# DOC-010: Unnecessary sudo usage in RUN instruction

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-010` |
| **Category** | `docker` |
| **Default Severity** | `WARNING` |

## Description
Commands in Docker RUN instructions execute with root privileges by default, making 'sudo' redundant and error-prone.

## Why This Matters
Detecting and addressing unnecessary sudo usage in run instruction prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Remove 'sudo' from RUN instructions during image build.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DOC-010
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DOC-010" = "off" # or "warning", "error"
```
