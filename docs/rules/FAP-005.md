# FAP-005: Missing HTTP client timeout configuration

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-005` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
HTTP client (such as httpx.AsyncClient, httpx.Client, or aiohttp.ClientSession) instantiated without an explicit timeout.

## Why This Matters
Detecting and addressing missing http client timeout configuration prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Configure an explicit timeout (e.g. timeout=10.0) to prevent hanging connections.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-005
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-005" = "off" # or "warning", "error"
```
