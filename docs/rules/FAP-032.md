# FAP-032: Redundant jsonable_encoder with response_model

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-032` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Calling jsonable_encoder() inside a route handler that already declares response_model causes double serialization, reducing throughput.

## Why This Matters
Detecting and addressing redundant jsonable_encoder with response_model prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Return raw objects or dicts directly and let FastAPI's response_model handle serialization.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-032
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-032" = "off" # or "warning", "error"
```
