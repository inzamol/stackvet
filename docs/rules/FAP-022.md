# FAP-022: WebSocket route missing await websocket.accept()

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-022` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
WebSocket endpoint sends or receives data before calling 'await websocket.accept()', which causes runtime errors.

## Why This Matters
Detecting and addressing websocket route missing await websocket.accept() prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Call 'await websocket.accept()' before reading or writing data to the WebSocket.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-022
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-022" = "off" # or "warning", "error"
```
