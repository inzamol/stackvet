# SQL-028: Thread-local scoped_session used in async context

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-028` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Using thread-local scoped_session in async applications causes session sharing across coroutines and race conditions.

## Why This Matters
Detecting and addressing thread-local scoped_session used in async context prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use async_scoped_session(..., scopefunc=asyncio.current_task) or dependency injection per request.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-028
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-028" = "off" # or "warning", "error"
```
