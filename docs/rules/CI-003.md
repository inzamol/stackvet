# CI-003: Deprecated or outdated CI action version

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `CI-003` |
| **Category** | `ci` |
| **Default Severity** | `INFO` |

## Description
Workflow references a deprecated or end-of-life GitHub Actions version.

## Why This Matters
Detecting and addressing deprecated or outdated ci action version prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Upgrade GitHub Actions to current stable major releases (e.g. actions/checkout@v4).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore CI-003
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"CI-003" = "off" # or "warning", "error"
```
