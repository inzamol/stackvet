# FAP-036: Mutating app.state inside route handler

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-036` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Mutating request.app.state or app.state inside per-request route handlers introduces concurrency race conditions. Application state should be initialized in lifespan context managers.

## Why This Matters
Detecting and addressing mutating app.state inside route handler prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Initialize shared state in the lifespan context manager before startup rather than modifying app.state in route handlers.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-036
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-036" = "off" # or "warning", "error"
```
