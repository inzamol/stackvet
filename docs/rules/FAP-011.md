# FAP-011: Mutable default value in route parameter

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-011` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Route handler uses a mutable default argument (e.g. list or dict), which can leak state across concurrent requests.

## Why This Matters
Detecting and addressing mutable default value in route parameter prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use None as default (e.g. filters: list[str] | None = None) or use Field(default_factory=list).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-011
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-011" = "off" # or "warning", "error"
```
