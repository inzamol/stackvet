# FAP-023: Deprecated Pydantic v1 Config class

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-023` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Pydantic schema uses deprecated inner 'class Config:' instead of Pydantic v2 'model_config = ConfigDict(...)'.

## Why This Matters
Detecting and addressing deprecated pydantic v1 config class prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Migrate inner 'class Config:' to 'model_config = ConfigDict(...)'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-023
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-023" = "off" # or "warning", "error"
```
