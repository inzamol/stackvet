# NXT-001: Server Component Client API

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `NXT-001` |
| **Category** | `nextjs` |
| **Default Severity** | `ERROR` |

## Description
Client hooks or browser globals used in Server Component without 'use client'.

## Why This Matters
Detecting and addressing server component client api prevents runtime failures, dependency conflicts, or configuration drift in production environments.
