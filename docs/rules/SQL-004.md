# SQL-004: Raw SQL string interpolation (SQL Injection Risk)

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-004` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Constructing SQL queries using f-strings or string formatting with text() or cursor.execute() introduces severe SQL injection vulnerabilities.

## Why This Matters
Detecting and addressing raw sql string interpolation (sql injection risk) prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use bound query parameters with text('SELECT ... WHERE id = :id'), {'id': user_val}.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-004
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-004" = "off" # or "warning", "error"
```
