# FAP-014: Potential path traversal in FileResponse

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-014` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
FileResponse initialized directly with an unvalidated path variable from route parameters, risking arbitrary file read vulnerabilities.

## Why This Matters
Detecting and addressing potential path traversal in fileresponse prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Validate and resolve the file path against a trusted base directory before passing to FileResponse.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-014
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-014" = "off" # or "warning", "error"
```
