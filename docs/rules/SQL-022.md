# SQL-022: Large binary or heavy text column without deferred/load_only strategy

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-022` |
| **Category** | `framework` |
| **Default Severity** | `INFO` |

## Description
Model includes LargeBinary or Large Text column without deferred() loading, causing heavy memory consumption during full-table selects.

## Why This Matters
Detecting and addressing large binary or heavy text column without deferred/load_only strategy prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Wrap large blob/text columns with 'deferred(Column(LargeBinary))' or use select(Model).options(load_only(...)).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-022
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-022" = "off" # or "warning", "error"
```
