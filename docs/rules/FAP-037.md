# FAP-037: SecurityScopes declared with Depends instead of Security

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-037` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
SecurityScopes parameter declared in a dependency using Depends(...) will not receive requested scopes. Use Security(dependency, scopes=[...]) instead.

## Why This Matters
Detecting and addressing securityscopes declared with depends instead of security prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use 'Security(dependency, scopes=[...])' when protecting endpoints with OAuth2 SecurityScopes.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-037
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-037" = "off" # or "warning", "error"
```
