# DOC-006: Sensitive file copied into Docker image

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-006` |
| **Category** | `docker` |
| **Default Severity** | `ERROR` |

## Description
The Dockerfile explicitly copies sensitive files (.env, private keys, or credentials) into the container image layer.

## Why This Matters
Detecting and addressing sensitive file copied into docker image prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Remove sensitive files from COPY instructions and use Docker BuildKit secrets (--mount=type=secret) or runtime environment variables instead.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DOC-006
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DOC-006" = "off" # or "warning", "error"
```
