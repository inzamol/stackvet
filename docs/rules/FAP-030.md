# FAP-030: Missing route summary or docstring for OpenAPI documentation

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-030` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Public route endpoint does not provide a docstring, 'summary', or 'description', resulting in sparse and incomplete OpenAPI documentation.

## Why This Matters
Detecting and addressing missing route summary or docstring for openapi documentation prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add a function docstring or pass 'summary=...' in the route decorator.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-030
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-030" = "off" # or "warning", "error"
```
