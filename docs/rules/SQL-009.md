# SQL-009: expire_on_commit=True in AsyncSession

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-009` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Configuring AsyncSession or async_sessionmaker with expire_on_commit=True (the default) causes MissingGreenlet exceptions when accessing committed model attributes.

## Why This Matters
Detecting and addressing expire_on_commit=true in asyncsession prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Set 'expire_on_commit=False' when instantiating AsyncSession or async_sessionmaker.


```toml
[rules]
```
