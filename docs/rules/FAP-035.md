# FAP-035: Raw Exception raised instead of HTTPException

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-035` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Raising generic Exception, ValueError, or RuntimeError in route handlers triggers uncaught 500 Internal Server Errors instead of structured REST HTTP error responses.

## Why This Matters
Detecting and addressing raw exception raised instead of httpexception prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Raise 'HTTPException(status_code=..., detail=...)' for predictable API client error responses.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-035
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-035" = "off" # or "warning", "error"
```
