# CI-001: CI Python matrix version mismatch

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `CI-001` |
| **Category** | `ci` |
| **Default Severity** | `WARNING` |

## Description
CI workflow tests Python versions incompatible with declared project requires-python or classifiers.

## Why This Matters
Detecting and addressing ci python matrix version mismatch prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Align CI test matrix versions with supported project Python ranges.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore CI-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"CI-001" = "off" # or "warning", "error"
```
