# RCT-004: Missing Key in List

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `RCT-004` |
| **Category** | `react` |
| **Default Severity** | `WARN` |

## Description
JSX element inside .map() loop is missing a unique 'key' prop.

## Why This Matters
Detecting and addressing missing key in list prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Provide a stable unique identifier as the key prop: <Item key={item.id} />.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore RCT-004
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"RCT-004" = "off" # or "warning", "error"
```
