# SQL-012: Relationship cascade delete without ForeignKey ondelete CASCADE

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-012` |
| **Category** | `framework` |
| **Default Severity** | `INFO` |

## Description
Configuring relationship cascade='all, delete-orphan' without database-level ondelete='CASCADE' on ForeignKey forces slow Python-side row-by-row deletion.

## Why This Matters
Detecting and addressing relationship cascade delete without foreignkey ondelete cascade prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add ondelete='CASCADE' to ForeignKey and passive_deletes=True to relationship for database-level cascading.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-012
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-012" = "off" # or "warning", "error"
```
