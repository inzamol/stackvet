# FAP-001: Blocking call or CPU-bound operation in async endpoint

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-001` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Synchronous blocking operations (e.g. time.sleep, requests, subprocess, synchronous DB queries) or CPU-bound hashing called inside an async def FastAPI route handler block the asyncio event loop.

## Why This Matters
Detecting and addressing blocking call or cpu-bound operation in async endpoint prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use non-blocking async alternatives (e.g. asyncio.sleep, httpx.AsyncClient) or run blocking/CPU calls in worker threads via anyio.to_thread.run_sync or fastapi.concurrency.run_in_threadpool.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-001" = "off" # or "warning", "error"
```
