# FAP-038: Hardcoded HTTP status code integer

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-038` |
| **Category** | `framework` |
| **Default Severity** | `INFO` |

## Description
Using integer literals for status_code (e.g. status_code=201) reduces readability compared to named constants like status.HTTP_201_CREATED.

## Why This Matters
Detecting and addressing hardcoded http status code integer prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Import status from fastapi (or HTTPStatus from http) and use named constants (e.g. status.HTTP_201_CREATED).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-038
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-038" = "off" # or "warning", "error"
```
