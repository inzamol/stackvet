# FAP-027: Dependency parameter missing type annotation

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-027` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Route parameter initialized with 'Depends(...)', 'Query(...)', or 'Path(...)' does not specify a type annotation, disabling FastAPI schema generation and static type checking.

## Why This Matters
Detecting and addressing dependency parameter missing type annotation prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add explicit type annotation: 'param: Type = Depends(...)' or 'param: Annotated[Type, Depends(...)]'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-027
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-027" = "off" # or "warning", "error"
```
