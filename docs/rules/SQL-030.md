# SQL-030: Direct DBAPI raw_connection() used without cleanup

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-030` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Calling engine.raw_connection() bypasses connection pool management and leaks connections if not closed explicitly.

## Why This Matters
Detecting and addressing direct dbapi raw_connection() used without cleanup prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Always close raw DBAPI connections in a try...finally block: 'raw_conn = engine.raw_connection(); try: ... finally: raw_conn.close()'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-030
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-030" = "off" # or "warning", "error"
```
