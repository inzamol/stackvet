# ENV-003: CI runtime drift

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `ENV-003` |
| **Category** | `environment` |
| **Default Severity** | `WARNING` |

## Description
CI workflow test matrix does not cover or differs from declared project Python versions.

## Why This Matters
Detecting and addressing ci runtime drift prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Align your CI matrix with the Python versions specified in pyproject.toml.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore ENV-003
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"ENV-003" = "off" # or "warning", "error"
```
