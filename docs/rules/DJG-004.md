# DJG-004: Potential N+1 database query in loop

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DJG-004` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
QuerySet execution inside loop causes N+1 query overhead.

## Why This Matters
Detecting and addressing potential n+1 database query in loop prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Prefetch related relations before looping: queryset.prefetch_related('...').

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DJG-004
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DJG-004" = "off" # or "warning", "error"
```
