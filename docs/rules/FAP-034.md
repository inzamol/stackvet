# FAP-034: Missing await on request.json() or request.body()

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-034` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Calling request.json() or request.body() without 'await' inside an async def route handler assigns an un-awaited coroutine instead of parsed data.

## Why This Matters
Detecting and addressing missing await on request.json() or request.body() prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add 'await' before 'request.json()' or 'request.body()'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-034
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-034" = "off" # or "warning", "error"
```
