# DEP-002: Missing dependency declaration

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DEP-002` |
| **Category** | `dependency` |
| **Default Severity** | `ERROR` |

## Description
A third-party package is imported in source code but is not declared in project dependencies.

## Why This Matters
Detecting and addressing missing dependency declaration prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add the missing package to your pyproject.toml or requirements.txt.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DEP-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DEP-002" = "off" # or "warning", "error"
```
