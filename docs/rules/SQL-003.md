# SQL-003: Synchronous DB operation in async event loop

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-003` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Invoking synchronous database engine calls or synchronous session operations inside an async def function blocks the asyncio event loop.

## Why This Matters
Detecting and addressing synchronous db operation in async event loop prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use SQLAlchemy async extension ('create_async_engine' and 'AsyncSession') with async drivers (e.g. asyncpg, aiosqlite).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-003
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-003" = "off" # or "warning", "error"
```
