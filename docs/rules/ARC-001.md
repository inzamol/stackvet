# ARC-001: Architecture layer violation

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `ARC-001` |
| **Category** | `architecture` |
| **Default Severity** | `WARNING` |

## Description
A module in an upper architectural layer directly imports a lower layer bypassing intermediate abstraction layers, or a lower layer imports an upper layer.

## Why This Matters
Detecting and addressing architecture layer violation prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Route access through intermediate service/repository layers or invert the dependency using interfaces.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore ARC-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"ARC-001" = "off" # or "warning", "error"
```
