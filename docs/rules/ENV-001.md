# ENV-001: Python version drift

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `ENV-001` |
| **Category** | `environment` |
| **Default Severity** | `WARNING` |

## Description
The active Python interpreter version differs from the project's target runtime specification.

## Why This Matters
Detecting and addressing python version drift prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Ensure the virtual environment is built using the configured target Python version.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore ENV-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"ENV-001" = "off" # or "warning", "error"
```
