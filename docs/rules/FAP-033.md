# FAP-033: Missing from_attributes=True in ORM response schema

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-033` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Pydantic response model for ORM/database objects is missing 'model_config = ConfigDict(from_attributes=True)', causing validation failures when serializing ORM instances.

## Why This Matters
Detecting and addressing missing from_attributes=true in orm response schema prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add 'model_config = ConfigDict(from_attributes=True)' to the Pydantic schema.


```toml
[rules]
```
