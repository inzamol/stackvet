# FAP-031: Prefer typing.Annotated over parameter default assignment

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-031` |
| **Category** | `framework` |
| **Default Severity** | `INFO` |

## Description
FastAPI strongly recommends using standard typing.Annotated[Type, Depends(...)] instead of parameter default values for cleaner typing and reusable dependencies.

## Why This Matters
Detecting and addressing prefer typing.annotated over parameter default assignment prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Refactor parameter to 'param: Annotated[Type, Depends(...)]' or 'param: Annotated[Type, Query(...)]'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-031
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-031" = "off" # or "warning", "error"
```
