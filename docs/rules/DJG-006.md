# DJG-006: Missing CSRF Protection Middleware

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DJG-006` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
MIDDLEWARE list is missing 'django.middleware.csrf.CsrfViewMiddleware'.

## Why This Matters
Detecting and addressing missing csrf protection middleware prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add 'django.middleware.csrf.CsrfViewMiddleware' to MIDDLEWARE.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DJG-006
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DJG-006" = "off" # or "warning", "error"
```
