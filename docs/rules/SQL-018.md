# SQL-018: Excessive connection pool size in single application instance

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-018` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
create_engine configured with pool_size or max_overflow > 50 in a single instance, risking database connection exhaustion.

## Why This Matters
Detecting and addressing excessive connection pool size in single application instance prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Keep pool_size between 5 and 20 per instance and use external connection poolers (e.g. pgBouncer) for scaling.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-018
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-018" = "off" # or "warning", "error"
```
