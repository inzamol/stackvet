# FAP-026: Deprecated Pydantic v1 @validator or @root_validator

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-026` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Using deprecated Pydantic v1 '@validator' or '@root_validator' decorators instead of Pydantic v2 '@field_validator' or '@model_validator'.

## Why This Matters
Detecting and addressing deprecated pydantic v1 @validator or @root_validator prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Migrate to '@field_validator' or '@model_validator' from pydantic.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-026
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-026" = "off" # or "warning", "error"
```
