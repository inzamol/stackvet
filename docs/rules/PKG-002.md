# PKG-002: Invalid project configuration

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `PKG-002` |
| **Category** | `packaging` |
| **Default Severity** | `ERROR` |

## Description
The project configuration file contains syntax errors or invalid keys.

## Why This Matters
Detecting and addressing invalid project configuration prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Fix configuration syntax to conform to PEP 621 / tool specifications.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore PKG-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"PKG-002" = "off" # or "warning", "error"
```
