# FAP-002: Blocking dependency in async path

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-002` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
An async route handler depends on a dependency (via Depends) that executes blocking synchronous I/O or CPU operations.

## Why This Matters
Detecting and addressing blocking dependency in async path prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Refactor dependency to use async operations or execute in a worker threadpool.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-002" = "off" # or "warning", "error"
```
