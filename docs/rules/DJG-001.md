# DJG-001: Insecure hardcoded DEBUG = True in Django settings

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DJG-001` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Django settings hardcodes 'DEBUG = True' without environment variable fallback, risking sensitive traceback exposure.

## Why This Matters
Detecting and addressing insecure hardcoded debug = true in django settings prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Load DEBUG dynamically from an environment variable: os.getenv('DJANGO_DEBUG', 'False').lower() == 'true'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DJG-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DJG-001" = "off" # or "warning", "error"
```
