# DOC-014: Web server entrypoint missing EXPOSE instruction

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-014` |
| **Category** | `docker` |
| **Default Severity** | `INFO` |

## Description
The container starts a web server but does not declare the listening network port via EXPOSE.

## Why This Matters
Detecting and addressing web server entrypoint missing expose instruction prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add 'EXPOSE <port>' (e.g. 'EXPOSE 8000') to document the port on which the container listens.

## Configuration & Suppression

```python

```

```toml
[rules]
"DOC-014" = "off" # or "warning", "error"
```
