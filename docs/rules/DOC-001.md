# DOC-001: Inefficient Docker layer caching

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-001` |
| **Category** | `docker` |
| **Default Severity** | `WARNING` |

## Description
Source code is copied before package dependencies are installed, invalidating the build cache on every code change.

## Why This Matters
Detecting and addressing inefficient docker layer caching prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Copy dependency manifests (e.g. pyproject.toml, requirements.txt) and install packages before copying the full project directory ('COPY . .').

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DOC-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DOC-001" = "off" # or "warning", "error"
```
