# DEP-007: Undeclared transitive dependency

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DEP-007` |
| **Category** | `dependency` |
| **Default Severity** | `WARNING` |

## Description
A package is imported in source code and provided transitively by a dependency, but is not declared directly in project dependencies.

## Why This Matters
Detecting and addressing undeclared transitive dependency prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add the transitive dependency directly to your pyproject.toml or requirements.txt.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DEP-007
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DEP-007" = "off" # or "warning", "error"
```
