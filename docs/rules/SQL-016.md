# SQL-016: Missing database migration configuration (Alembic)

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-016` |
| **Category** | `framework` |
| **Default Severity** | `INFO` |

## Description
SQLAlchemy database models are defined in the project, but no Alembic migrations directory or alembic.ini configuration exists.

## Why This Matters
Detecting and addressing missing database migration configuration (alembic) prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Initialize database migrations using 'alembic init alembic'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-016
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-016" = "off" # or "warning", "error"
```
