# DOC-009: Deprecated MAINTAINER instruction used

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-009` |
| **Category** | `docker` |
| **Default Severity** | `INFO` |

## Description
The MAINTAINER instruction is deprecated in Dockerfile syntax in favor of metadata labels.

## Why This Matters
Detecting and addressing deprecated maintainer instruction used prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Replace 'MAINTAINER <author>' with 'LABEL maintainer=\

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DOC-009
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DOC-009" = "off" # or "warning", "error"
```
