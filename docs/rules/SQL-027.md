# SQL-027: Unsafe concurrent numeric balance or counter update without with_for_update()

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-027` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Querying a record and updating numeric counters or balance fields without row-level locking (with_for_update()) causes lost update race conditions.

## Why This Matters
Detecting and addressing unsafe concurrent numeric balance or counter update without with_for_update() prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Lock rows with 'select(...).with_for_update()' or use atomic SQL increments 'update(Account).values(balance=Account.balance - amt)'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python

```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-027" = "off" # or "warning", "error"
```
