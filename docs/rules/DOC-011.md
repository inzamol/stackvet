# DOC-011: apt-get install without cleanup or --no-install-recommends

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-011` |
| **Category** | `docker` |
| **Default Severity** | `INFO` |

## Description
apt-get install inside Dockerfile leaves package lists and recommended dependencies in image layers, bloating image size.

## Why This Matters
Detecting and addressing apt-get install without cleanup or --no-install-recommends prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use 'apt-get install -y --no-install-recommends <pkgs> && rm -rf /var/lib/apt/lists/*' in the same RUN layer.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python

```

Or configure a rule override in `.stackvet.toml`:

```toml

```
