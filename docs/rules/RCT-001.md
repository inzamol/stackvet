# RCT-001: Missing Hook Dependencies

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `RCT-001` |
| **Category** | `react` |
| **Default Severity** | `WARN` |

## Description
useEffect or useCallback missing referenced closure variables in dependency array.

## Why This Matters
Detecting and addressing missing hook dependencies prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Include all referenced variables in the dependency array or wrap in useCallback.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore RCT-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"RCT-001" = "off" # or "warning", "error"
```
