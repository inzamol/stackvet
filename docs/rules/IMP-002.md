# IMP-002: Unresolved local import

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `IMP-002` |
| **Category** | `architecture` |
| **Default Severity** | `ERROR` |

## Description
A local module imported in source code could not be resolved on the project's Python path.

## Why This Matters
Detecting and addressing unresolved local import prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Verify the module name and ensure source directory is marked on the PYTHONPATH or package root.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore IMP-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"IMP-002" = "off" # or "warning", "error"
```
