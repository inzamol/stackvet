# SQL-011: Unbounded SELECT query without limit or pagination

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-011` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Calling .all() on queries against database tables without limit() or pagination clauses risks memory exhaustion on large datasets.

## Why This Matters
Detecting and addressing unbounded select query without limit or pagination prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add '.limit(limit)' and pagination parameters to query statements.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-011
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-011" = "off" # or "warning", "error"
```
