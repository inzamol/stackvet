# FAP-020: Potential open redirect in RedirectResponse

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-020` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
RedirectResponse initialized directly with user-supplied URL parameter without domain whitelist validation.

## Why This Matters
Detecting and addressing potential open redirect in redirectresponse prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Validate that the redirect target is a relative path or matches an allowed domain whitelist.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-020
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-020" = "off" # or "warning", "error"
```
