# FAP-012: Invalid exception handler signature

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-012` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Custom @app.exception_handler function does not take the required (request, exc) parameters, causing runtime crashes.

## Why This Matters
Detecting and addressing invalid exception handler signature prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Ensure custom exception handlers accept exactly two parameters: '(request: Request, exc: Exception)'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-012
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-012" = "off" # or "warning", "error"
```
