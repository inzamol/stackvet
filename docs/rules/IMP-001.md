# IMP-001: Circular import detected

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `IMP-001` |
| **Category** | `architecture` |
| **Default Severity** | `ERROR` |

## Description
An import cycle exists between two or more modules, which may cause runtime initialization errors.

## Why This Matters
Detecting and addressing circular import detected prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Refactor shared dependencies into a separate module or use deferred/lazy imports.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore IMP-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"IMP-001" = "off" # or "warning", "error"
```
