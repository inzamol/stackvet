# RCT-003: Direct State Mutation

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `RCT-003` |
| **Category** | `react` |
| **Default Severity** | `ERROR` |

## Description
Mutating state directly (state.val = 1) rather than using state dispatcher.

## Why This Matters
Detecting and addressing direct state mutation prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use setState dispatcher or produce an immutable copy.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore RCT-003
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"RCT-003" = "off" # or "warning", "error"
```
