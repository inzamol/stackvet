# SQL-002: Session instantiated without context manager or cleanup

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-002` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Instantiating a Session without a with-statement context manager or try...finally session.close() causes database connection pool exhaustion.

## Why This Matters
Detecting and addressing session instantiated without context manager or cleanup prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use 'with SessionLocal() as session:' or wrap session lifecycle in a context manager / dependency yield.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-002" = "off" # or "warning", "error"
```
