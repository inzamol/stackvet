# FAP-009: Untyped or unvalidated request body

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-009` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Route handler accepts a raw 'dict', 'Any', or untyped Body parameter instead of a Pydantic model, bypassing automatic request validation.

## Why This Matters
Detecting and addressing untyped or unvalidated request body prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Define a Pydantic BaseModel schema for the request payload to ensure type safety and validation.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-009
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-009" = "off" # or "warning", "error"
```
