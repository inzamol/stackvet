# DJG-003: Insecure wildcard ALLOWED_HOSTS in Django settings

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DJG-003` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
ALLOWED_HOSTS contains wildcard '*' allowing Host header poisoning.

## Why This Matters
Detecting and addressing insecure wildcard allowed_hosts in django settings prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Explicitly define allowed domain names or load from environment.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DJG-003
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DJG-003" = "off" # or "warning", "error"
```
