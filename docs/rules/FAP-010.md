# FAP-010: Shadowed or duplicate route endpoint

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-010` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Multiple route handlers are registered with the identical HTTP method and path on the same app/router, causing one to shadow the other.

## Why This Matters
Detecting and addressing shadowed or duplicate route endpoint prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Ensure all routes have unique method and path combinations, or combine related logic into a single handler.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-010
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-010" = "off" # or "warning", "error"
```
