# DOC-004: Missing .dockerignore file

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-004` |
| **Category** | `docker` |
| **Default Severity** | `WARNING` |

## Description
A Dockerfile exists in the project but no .dockerignore file is present, risking baking local virtualenvs, credentials, and temp files into the image.

## Why This Matters
Detecting and addressing missing .dockerignore file prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Create a .dockerignore file in the repository root excluding .git, .venv, __pycache__, and sensitive files.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DOC-004
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DOC-004" = "off" # or "warning", "error"
```
