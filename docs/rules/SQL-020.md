# SQL-020: Declarative ORM Model missing primary key definition

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-020` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Declarative ORM model defined without at least one primary key column (primary_key=True), which will cause runtime ORM mapping failures.

## Why This Matters
Detecting and addressing declarative orm model missing primary key definition prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Define at least one column with 'primary_key=True' or 'mapped_column(primary_key=True)'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-020
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-020" = "off" # or "warning", "error"
```
