# SQL-023: ForeignKey column defined without index=True

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-023` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
ForeignKey column created without index=True, causing expensive sequential scans during joins, foreign key lookups, and cascade operations.

## Why This Matters
Detecting and addressing foreignkey column defined without index=true prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add 'index=True' to ForeignKey column definitions (e.g. Column(Integer, ForeignKey('users.id'), index=True)).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-023
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-023" = "off" # or "warning", "error"
```
