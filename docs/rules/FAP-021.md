# FAP-021: Router included without tags or prefix

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-021` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
app.include_router() called without 'tags' or 'prefix', leading to unorganized OpenAPI documentation and URL clashes.

## Why This Matters
Detecting and addressing router included without tags or prefix prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Provide 'prefix' and 'tags' when including routers (e.g. app.include_router(user_router, prefix='/users', tags=['Users'])).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-021
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-021" = "off" # or "warning", "error"
```
