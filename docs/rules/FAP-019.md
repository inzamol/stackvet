# FAP-019: Insecure cookie configuration

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-019` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
response.set_cookie() called without httponly=True or secure=True flags, exposing cookies to XSS or network interception.

## Why This Matters
Detecting and addressing insecure cookie configuration prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Set 'httponly=True' and 'secure=True' when storing sensitive session or auth cookies.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-019
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-019" = "off" # or "warning", "error"
```
