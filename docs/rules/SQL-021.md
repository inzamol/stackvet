# SQL-021: Missing session.rollback() in database exception handler

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-021` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Catching exceptions around database queries/mutations without invoking session.rollback() leaves the session in an unusable invalid state.

## Why This Matters
Detecting and addressing missing session.rollback() in database exception handler prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add 'session.rollback()' in exception handlers or use 'with session.begin():' for automatic rollback on error.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-021
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-021" = "off" # or "warning", "error"
```
