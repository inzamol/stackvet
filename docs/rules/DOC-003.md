# DOC-003: Unpinned base image tag

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-003` |
| **Category** | `docker` |
| **Default Severity** | `INFO` |

## Description
The base image uses ':latest' or an unpinned tag, which leads to non-reproducible and unpredictable builds.

## Why This Matters
Detecting and addressing unpinned base image tag prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Pin the base image to a specific version or hash (e.g. 'python:3.12-slim-bookworm').

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DOC-003
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DOC-003" = "off" # or "warning", "error"
```
