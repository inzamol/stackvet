# RCT-005: Barrel Import Bloat

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `RCT-005` |
| **Category** | `react` |
| **Default Severity** | `WARN` |

## Description
Importing from root barrel file causing excessive bundle size.

## Why This Matters
Detecting and addressing barrel import bloat prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Import from specific subpaths (e.g. '@mui/material/Button').

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore RCT-005
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"RCT-005" = "off" # or "warning", "error"
```
