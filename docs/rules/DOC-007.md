# DOC-007: Missing HEALTHCHECK instruction

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-007` |
| **Category** | `docker` |
| **Default Severity** | `INFO` |

## Description
The Dockerfile configures a network service or entrypoint without defining a container HEALTHCHECK.

## Why This Matters
Detecting and addressing missing healthcheck instruction prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add a HEALTHCHECK instruction (e.g. 'HEALTHCHECK --interval=30s CMD curl -f http://localhost:8000/health || exit 1').

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DOC-007
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DOC-007" = "off" # or "warning", "error"
```
