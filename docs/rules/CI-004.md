# CI-004: Missing test or quality gate in CI workflow

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `CI-004` |
| **Category** | `ci` |
| **Default Severity** | `INFO` |

## Description
Pull request / push workflow contains no test suite, linter, or health checks.

## Why This Matters
Detecting and addressing missing test or quality gate in ci workflow prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Add automated test or lint steps (e.g. pytest, ruff, qv scan --ci).

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore CI-004
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"CI-004" = "off" # or "warning", "error"
```
