# FAP-015: Blocking file I/O in async endpoint

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-015` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Using synchronous open() or blocking file read/write operations inside an async def route handler blocks the event loop.

## Why This Matters
Detecting and addressing blocking file i/o in async endpoint prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use 'aiofiles', 'anyio.Path', or run file I/O in a synchronous def route handler.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-015
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-015" = "off" # or "warning", "error"
```
