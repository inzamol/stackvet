# SQL-019: NullPool configured in persistent web application

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-019` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Using NullPool in persistent web servers disables connection pooling and creates high latency TCP connection overhead on every request.

## Why This Matters
Detecting and addressing nullpool configured in persistent web application prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use default QueuePool or AsyncAdaptedQueuePool for persistent web applications; reserve NullPool for AWS Lambda/serverless.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-019
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-019" = "off" # or "warning", "error"
```
