# SQL-006: Missing relationship eager loading strategy in async session

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-006` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Accessing lazy-loaded ORM relationships without explicit joinedload/selectinload in async sessions triggers MissingGreenlet errors.

## Why This Matters
Detecting and addressing missing relationship eager loading strategy in async session prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Specify 'options(selectinload(Model.relation))' or set lazy='selectin' on relationship definition.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-006
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-006" = "off" # or "warning", "error"
```
