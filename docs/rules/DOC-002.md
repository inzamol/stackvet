# DOC-002: Root user container execution

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `DOC-002` |
| **Category** | `docker` |
| **Default Severity** | `WARNING` |

## Description
The Dockerfile configures an execution entrypoint (CMD/ENTRYPOINT) without specifying a non-root USER.

## Why This Matters
Detecting and addressing root user container execution prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Create and switch to a non-privileged user (e.g. 'RUN useradd -m appuser && USER appuser') before the container entrypoint.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore DOC-002
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"DOC-002" = "off" # or "warning", "error"
```
