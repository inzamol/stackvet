# FAP-007: Unsafe yield dependency without try/finally

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `FAP-007` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
A generator dependency using yield does not wrap cleanup code in a try...finally block, causing resource and connection leaks on exceptions.

## Why This Matters
Detecting and addressing unsafe yield dependency without try/finally prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Wrap the yield and teardown logic in a try...finally block to guarantee resource cleanup.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore FAP-007
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"FAP-007" = "off" # or "warning", "error"
```
