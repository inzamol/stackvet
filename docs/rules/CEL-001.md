# CEL-001: Insecure Celery pickle serializer enabled

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `CEL-001` |
| **Category** | `framework` |
| **Default Severity** | `ERROR` |

## Description
Celery serializer setting uses 'pickle', allowing arbitrary code execution if brokers are compromised.

## Why This Matters
Detecting and addressing insecure celery pickle serializer enabled prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use secure serialization formats like 'json' or 'msgpack'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore CEL-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"CEL-001" = "off" # or "warning", "error"
```
