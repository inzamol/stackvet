# SQL-007: Uncommitted transaction in mutation function

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-007` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Session performs mutations (session.add / session.delete) but never executes session.commit() or enters a transaction with session.begin().

## Why This Matters
Detecting and addressing uncommitted transaction in mutation function prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Ensure mutations are committed with 'await session.commit()' or executed inside 'with session.begin():'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-007
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-007" = "off" # or "warning", "error"
```
