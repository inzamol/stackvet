# SEC-001: Security analysis unavailable

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SEC-001` |
| **Category** | `security` |
| **Default Severity** | `WARNING` |

## Description
The advisory database (OSV.dev) could not be reached to perform vulnerability checks.

## Why This Matters
Detecting and addressing security analysis unavailable prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Check your internet connection or run with --offline to skip security checks.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SEC-001
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SEC-001" = "off" # or "warning", "error"
```
