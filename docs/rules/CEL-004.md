# CEL-004: Blocking time.sleep() in asynchronous Celery task

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `CEL-004` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Async Celery task invokes 'time.sleep()', blocking the async event loop.

## Why This Matters
Detecting and addressing blocking time.sleep() in asynchronous celery task prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Use 'await asyncio.sleep()' instead of 'time.sleep()'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python

```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"CEL-004" = "off" # or "warning", "error"
```
