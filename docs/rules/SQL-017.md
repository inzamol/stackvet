# SQL-017: Mapped[...] attribute missing mapped_column() in 2.0 Declarative Model

| Attribute | Value |
|-----------|-------|
| **Rule ID** | `SQL-017` |
| **Category** | `framework` |
| **Default Severity** | `WARNING` |

## Description
Using legacy Column() or raw field assignment with Mapped[...] type annotations instead of SQLAlchemy 2.0's native mapped_column().

## Why This Matters
Detecting and addressing mapped[...] attribute missing mapped_column() in 2.0 declarative model prevents runtime failures, dependency conflicts, or configuration drift in production environments.

## Remediation
Replace 'col: Mapped[int] = Column(Integer)' with 'col: Mapped[int] = mapped_column()'.

## Configuration & Suppression
To suppress this rule for a specific file or line, add an inline comment:

```python
# stackvet:ignore SQL-017
```

Or configure a rule override in `.stackvet.toml`:

```toml
[rules]
"SQL-017" = "off" # or "warning", "error"
```
